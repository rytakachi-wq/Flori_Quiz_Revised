# 物語ムービー 絵コンテ(コマごとの顔・動きの指示用)

縦長のスマホ画面(9:16)。ズームなし。**コマ番号**(P1・①2 など)は、ムービー画面の左上に出ます。

## 指示の書き方
コマ番号ごとに、**顔**と**動き**を、下の「使えるもの」から選んで書いてください(時間を指定したいときは「0〜2秒 びっくりの絵、2秒〜 動くフロリ」のように)。

### 使えるもの
- **顔(はりつける絵)**:びっくり / しょんぼり / にっこり / にこにこ(**4種類。** 絵が増えたら、増やせます)
- **顔(動くフロリの表情)**:むむっ・うーん・にこっ・ふむ・しょんぼり・きりっ・にっこり・ぽかん・こまった・ぷんぷん・びっくり・にやり・あはは・うっとり・ぐぬぬ・ちょい困り・ちょいきり・おや・かしげ・ちょこん
- **腕・体の動き**:手を振る(wave・右/左)/ ばんざい(cheer)/ ぱたぱた(flap)/ 伸び(stretch)/ ぴょん(hop=跳ぶ)/ 腕を動かさない / 歩く(上下にゆれる)
- **体ぜんたいの動き**:びくっと大きくなる(1回)/ ゆっくりゆれる(しょんぼり)/ ぴょこぴょこはずむ / ぶるぶるふるえる(短く)
- **移動**:画面の左右に、歩いて出入り / ゆっくり消える
- **敵・ものの動き**:歩く・はねる・走る・回る・小さくなる・消える・ゆれる(コマを絵で描いてもらえば、もっと細かく動かせる)
