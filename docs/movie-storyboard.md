# 物語ムービー 絵コンテ

縦長のスマホ画面で、順に流れます。**ズームはしません**。ムービー画面の左上に、いま見ているコマの番号(P1・①2 など)が出ます。

**この表の使い方**:各コマの最後の「あなたの指示」に、そのコマの**顔**と**動き**を、書いてください(「0〜2秒 びっくりの顔」「3秒で手を振る」のように、時間も書けます)。書かなければ、いまの設定のままです。

## 選べるもの

| 項目 | 選べるもの |
|---|---|
| 顔の絵(はりつける) | びっくり / しょんぼり / にっこり / にこにこ |
| 動くフロリ自身の表情 | むむっ・うーん・にこっ・ふむ・しょんぼり・きりっ・にっこり・ぽかん・こまった・ぷんぷん・びっくり・にやり・あはは・うっとり・ぐぬぬ・おや・かしげ |
| 腕・体 | 手を振る / ばんざい / 腕をぱたぱた / つま先で伸びる / ぴょんと跳ぶ / 腕を動かさない / 歩く |
| 体ぜんたい | びくっと大きくなる / ゆっくり ゆれる(かなしい) / ぴょこぴょこ はずむ(うれしい) / ぶるぶる ふるえる(おこる・こわい) |
| 入り方・出方 | 画面の外から歩いて入る / 歩いて出ていく / だんだん消える |
