- **1. Aの両はしと、Bの片はしに同時に火をつけ、Aが燃えきったら、Bのもう片はしにも火をつける ◎**
- 2. Aの両はしに火をつけ、燃えきったら、Bの片はしに火をつける
- 3. Aの片はしに火をつけ、燃えきったら、Bの両はしに火をつける
- 4. AとBの両はしに、同時に火をつけ、Aが燃えきったら、Bを消す

解説: Aの両はしと、Bの片はしに、同時に火をつけます。Aは両はしから燃えるので、30分で燃えきります。そのとき、Bは、残り30分分です。そこでBのもう片はしにも火をつけると、残りは2倍の速さで燃えて、15分で燃えきります。30+15=45分です。

### o09  難しさ5

- 2. 穴の中心を通る、横の線で切る

ヒント: 全体も、穴も、それぞれ半分にしたいね。
