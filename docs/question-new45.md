### o08  難しさ5
燃えるのに、ちょうど1時間かかるひもが、2本あります。ひもは、太さが一定ではなく、半分の長さが燃えるのに、30分かかるとは限りません。2本のひもとライターだけで、ちょうど45分をはかるには?

- **1. Aの両はしと、Bの片はしに火をつけ、Aが燃えきったら、Bのもう片はしにも火をつける ◎**
- 2. Aの片はしに火をつけ、半分の長さが燃えたら、Bにも火をつける
- 3. AとBの片はしに同時に火をつけ、Aが燃えきったときに、はかり終える
- 4. Bの両はしに火をつけ、燃えきったら、Aの両はしに火をつける

解説: Aの両はしと、Bの片はしに、同時に火をつけます。Aは両はしから燃えるので、30分で燃えきります。そのとき、Bは、残り30分分です。そこでBのもう片はしにも火をつけると、残りは2倍の速さで燃えて、15分で燃えきります。30+15=45分です。
ヒント: 両はしから火をつけると、燃えきる時間は、どうなるかな?

### o09  難しさ5
4人のうち1人が、窓ガラスを割りました。A「割ったのはBだ」B「割ったのはDだ」C「私は割っていない」D「Bはうそを言っている」。本当のことを言っているのは、1人だけです。割ったのはだれ?

- 1. A
- 2. B
- **3. C ◎**
- 4. D

解説: Aが割ったなら、CとDが本当。Bが割ったなら、A、C、Dが本当。Dが割ったなら、BとCが本当で、どれも1人になりません。Cが割ったときだけ、本当のことを言うのは、Dだけです。
ヒント: 1人ずつ「この人が犯人」と決めて、本当の人の数を数えよう。
