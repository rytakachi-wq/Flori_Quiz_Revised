地球は、24時間で1回転しています。赤道(地球の真ん中の線)の近くと、北極(地球の一番上の北)の近くで、1日に地面が動く道のりが長いのは、どちら?

- 1. 北極の近く
- 2. どちらも同じ
- 3. どちらも動かない
- **4. 赤道の近く ◎**

解説: どちらも1日で1周しますが、赤道のまわりの円のほうが、ずっと大きいです。同じ時間で大きな円を回るので、赤道の近くのほうが、長い道のりを動きます。
ヒント: 同じ時間で、大きな円と小さな円を1周するなら?

### q56  難しさ3
海に近い地域は、内陸の地域より、冬に気温が下がりすぎないことが多いです。その理由は?

- 1. 海の近くは、冬でも太陽に近いから
- **2. 海の水はあたたまりにくく、冷めにくいから ◎**
- 3. 海から出る湯気が、地面をあたためるから
- 4. 海からの波が、冷たい風を止めるから

解説: 水は、あたたまりにくく冷めにくい性質があります。海の水が、冬でもあまり冷えないので、海に近い地域は、冬の気温が下がりすぎません。
ヒント: お風呂のお湯は、すぐ冷めるかな?

### q58  難しさ3
歴史の本の「紀元前100年」と「紀元前10年」(「紀元前」は、キリストが生まれたとされる年より前の年のこと)では、どちらのほうが今に近い?

- **1. 紀元前10年 ◎**
- 2. 紀元前100年
- 3. 同じ
- 4. 比べられない

解説: 紀元前では、キリストが生まれたとされる年に向かって、紀元前100年、紀元前10年と、年が進みます。だから、年の数が小さいほど今に近く、紀元前10年は、紀元前100年より90年、今に近いです。
ヒント: 年表の、0年に近いのは、どちらかな?

### q59  難しさ3
歴史では、100年のまとまりを「世紀」で数えます。1年〜100年が1世紀、101年〜200年が2世紀です。では、1850年は何世紀?

- 1. 18世紀
- **2. 19世紀 ◎**
- 3. 20世紀
- 4. 17世紀

解説: 101〜200年が2世紀なので、1801〜1900年が19世紀です。1850年は、その中に入ります。世紀の数は、年の上2けた(18)に、1を足した数になります。
ヒント: 1801年〜1900年は、何世紀かな?

### o08  難しさ5
部屋の外に、3つのスイッチ(A、B、C)があり、部屋の中に、電球が1つあります。スイッチのうち1つだけが、電球につながっています。部屋には、1回しか入れません。どのスイッチか、確実に分かる方法は?

- 1. スイッチを1つずつ押して、確かめる
- **2. Aをしばらくつけて消し、Bをつけたまま、部屋に入る ◎**
- 3. 3つとも、つけたまま入る
- 4. 3つとも、消したまま入る

解説: Aをしばらくつけて消し、Bをつけたまま入ります。電球がついていればB。消えていて熱ければA。消えていて冷たければCです。電球の熱を、手がかりにするのがコツです。
ヒント: 電球は、ついていると、どうなるかな?(光以外にも)

### o09  難しさ5

- 1. オオカミ
- **2. ヤギ ◎**
- 3. キャベツ
- 4. 何も乗せずに行く

解説: オオカミを先に運ぶと、残ったヤギがキャベツを食べます。キャベツを先に運ぶと、残ったオオカミがヤギを食べます。だから、最初は、ヤギを運びます。そのあと、オオカミを運び、ヤギを連れて戻って、キャベツを運び、最後にヤギを運びます。
ヒント: 先に残しても、食べられない組み合わせは、どれ?
