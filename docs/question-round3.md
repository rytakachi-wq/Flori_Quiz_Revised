### o05  オニ  難しさ5
4枚のカードがあります。カードの片面には数字、反対の面には色が書いてあります。いま、上になっている面は、「3」「8」「赤」「青」です。
「偶数のカードの裏は、赤」というルールが、守られているか確かめたいです。
そのために、裏をめくって確かめるカードは、どれ?

- **1. 「8」と「青」 ◎**
- 2. 「8」と「赤」
- 3. 「3」と「赤」
- 4. 「3」と「青」

解説: ルールをやぶっているカードがないか、探します。
・「8」は偶数です。裏が赤でなければ、ルールにそむくので、めくります。
・「青」は赤ではありません。裏が偶数だと、ルールにそむくので、めくります。
・「3」は偶数ではないので、裏が何色でも、ルールに関係ありません。
・「赤」は、裏が何の数字でも、ルールにそむきません。
ヒント: ルールが、やぶられる可能性のあるカードは?

### q83  地理歴史（難しい）  難しさ4
日本の都道府県のうち、いちばん多くの県と、境を接している県は?

- **1. 長野県 ◎**
- 2. 岐阜県
- 3. 埼玉県
- 4. 福島県

解説: 長野県は、新潟、富山、岐阜、愛知、静岡、山梨、埼玉、群馬の、8つの県と接していて、いちばん多いです。岐阜県と埼玉県は、7つです。
ヒント: 日本の、真ん中あたりの、山が多い県だよ。
