### q29  社会（ふつう）  難しさ2
広い野原で、雷が鳴りだしました。近くに、高い木が1本だけあります。どうするのが、よい?

- **1. 木から4m以上はなれて、低い姿勢でしゃがむ ◎**
- 2. 木の下で、雨宿りする
- 3. 木に、ぴったりくっついて立つ
- 4. 走って、木のてっぺんまで登る

解説: 雷は、高い物に落ちやすいです。木の下やそばは、雷が木から人に飛びうつることがあり、とても危険です。木から4m以上はなれて、低い姿勢で、しゃがみます。できるだけ早く、建物や車の中に入ります。
ヒント: 高い物には、雷が落ちやすいよ。

### o09  オニ  難しさ5
6本のマッチ棒を、全部使って、同じ大きさの正三角形を4つ作ります。マッチ棒は、折ったり、切ったりしません。どうすればいい?

- **1. 三角すい(立体)の形に組む ◎**
- 2. 星の形に、重ねて置く
- 3. 同じ平面に、4つ並べる
- 4. 作れない

解説: 平面では、6本で、正三角形は、最大でも2つしか作れません。でも、立体にして、三角すいの形に組むと、4つの面が、すべて同じ大きさの正三角形になります。底に3本、そこから頂点へ3本を立てます。
ヒント: 平面だけで考えないで、立体にしてみよう。

### q32  社会（ふつう）  難しさ2
災害に備えて、家に、非常食をそなえます。期限が切れるのを防ぐ、よい方法は?

- **1. ふだんの食事で食べて、食べた分を買い足す ◎**
- 2. ふだんは食べずに、大切に保管しておく
- 3. 1年分を、1度に全部食べる

### q88  数学（難しい）  難しさ4
カレンダーで、四角くかこんだ4つの日付(左上が8なら、8、9、15、16)を足したら、60になりました。左上の日付は?

- 1. 9日
- 2. 10日
- **3. 11日 ◎**
- 4. 12日

解説: 左上をxとすると、4つの日付は、x、x+1、x+7、x+8です。足すと、4x+16です。これが60なので、4x=44、x=11です。(11、12、18、19を足すと、60)
ヒント: となりの日付は+1、1つ下の段の日付は+7になるよ。

### q69  数学（難しい）  難しさ4
1日目に1円、2日目に2円、3日目に4円…と、毎日、前の日の2倍のお小遣いを、30日間もらいます。30日目にもらう金額は、約いくら?

- 1. 約5000万円
- **2. 約5億円 ◎**
- 3. 約50億円
- 4. 約500億円

解説: 毎日2倍なので、30日目は、1円を2倍する計算を、29回くり返した金額です。2を29回かけると、約5億3700万になります。だから、30日目だけで、約5億円です。
ヒント: 10日目は512円、20日目は、約52万円だよ。

### q92  科学（難しい）  難しさ4
水を入れたペットボトルの横に、小さな穴があいていて、水が飛び出しています。このペットボトルを、手ばなして落とすと、落ちている間、水は、どうなる?

### q84  言語文化（難しい）  難しさ4
次のうち、俳句で「冬」の季語は?

- 1. 夕立
- **2. 時雨 ◎**
- 3. 朧月
- 4. 稲妻

解説: 「時雨」は、秋の終わりから冬にかけて、ぱらぱらと降って、すぐにやむ雨で、冬の季語です。「夕立」は夏、「朧月」は春、「稲妻」は、秋の季語です。
ヒント: 冬の初めに降る、通り雨だよ。
