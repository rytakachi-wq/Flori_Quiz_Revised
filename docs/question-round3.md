### q29  社会（ふつう）  難しさ2
選挙の「期日前投票」とは、どんなしくみ?

- **1. 投票日より前に、投票できるしくみ ◎**
- 2. 投票を、お金で買えるしくみ
- 3. 1度した投票を、取り消せるしくみ
- 4. 投票する人を、くじで決めるしくみ

解説: 期日前投票は、投票日に、仕事や旅行などの用事があって行けない人が、投票日より前に、投票できるしくみです。投票する権利を、大切にするための方法です。
ヒント: 「期日」は、決められた日のこと。「前」に、投票するよ。

### o05  オニ  難しさ5
丸いケーキを、まっすぐな包丁で、3回切って、8つに分けたいです。切ったあとの、ケーキは、動かしません。どう切る?

- **1. たてに十字に2回切り、さらに横から、水平に1回切る ◎**
- 2. たてに、平行に3回切る
- 3. 3回とも、ななめに切る
- 4. 8つには、分けられない

解説: 上から見て、十字に2回切ると、4つに分かれます。そこへ、横から、水平に1回切ると、上と下に分かれて、全部で8つになります。平面だけで考えると、3回では、7つまでしか分けられません。立体であることが、ポイントです。
ヒント: ケーキには、厚みがあるよ。上と下に、分けられないかな?

### q84  言語文化（難しい）  難しさ4
歌舞伎で、客席の中を通って、舞台につながる、役者が出入りする、細長い道を、何という?

- **1. 花道 ◎**
- 2. 通り道
- 3. 橋掛かり
- 4. 廊下

解説: 歌舞伎の「花道」は、客席を通って、舞台につながる道です。役者が、ここを通って登場したり、見せ場を演じたりします。「橋掛かり」は、能の舞台にある、似たものです。

### q88  数学（難しい）  難しさ4
カレンダーで、四角くかこんだ4つの日付(左上が8なら、8、9、15、16)を足したら、60になりました。左上の日付は?

- 1. 9日
- 2. 10日
- **3. 11日 ◎**
- 4. 12日

解説: 四角くかこんだ4つの日付は、左上の日付、その1つ右、1つ下、右下です。1つ右は+1、1つ下は+7、右下は+8です。だから、合計は、左上の日付の4倍に、1+7+8=16を足した数になります。60−16=44で、44÷4=11です。左上は、11日です。(11、12、18、19を足すと、60)
ヒント: となりの日付は+1、1つ下の段の日付は+7になるよ。

### q69  数学（難しい）  難しさ4

- 1. 約1600円
- **2. 約16000円 ◎**
- 3. 約160000円
- 4. 約1600000円

解説: 1円、2円、4円、8円…と、毎日2倍にしていきます。11日目に1024円、12日目に2048円、13日目に4096円、14日目に8192円、15日目に16384円です。約1万6千円になります。
ヒント: 10日目は、512円だよ。
