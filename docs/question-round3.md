### o05  オニ  難しさ5
4枚のカードがあります。どのカードも、片面に数字、もう片面に色が書いてあります。いま見えている面は、「3」「8」「赤」「青」です。「数字が偶数なら、裏の色は必ず赤」というルールが、守られているか、確かめたいです。めくる必要があるカードは?

- **1. 「8」と「青」 ◎**
- 2. 「8」と「赤」
- 3. 「3」と「赤」
- 4. 「3」と「青」

解説: ルールをやぶっているカードがないか、探します。
・「8」は偶数です。裏が赤でなければ、ルールにそむくので、めくります。
・「青」は赤ではありません。裏が偶数だと、ルールにそむくので、めくります。
・「3」は偶数ではないので、裏が何色でも、ルールに関係ありません。
・「赤」は、裏が何の数字でも、ルールにそむきません。
ヒント: ルールが、やぶられる可能性のあるカードは?

### q83  地理歴史（難しい）  難しさ4
日本の47都道府県のうち、人口がいちばん少ない県は?

- **1. 鳥取県 ◎**
- 2. 島根県
- 3. 高知県
- 4. 福井県
