### q29  社会（ふつう）  難しさ2
道で財布を拾って、交番に届けました。持ち主が、決められた期間内に現れなかったら、財布は、どうなる?

- **1. 拾った人が、もらえる ◎**
- 2. 警察のものになる
- 3. 必ず、すてられる
- 4. 国のお金になる

解説: 落とし物は、交番に届けると、警察が保管します。持ち主が、3か月以内に現れないときは、拾った人が、もらえる権利を得ます。ただし、拾った人が、その権利を放棄することもできます。
ヒント: 拾って届けた人には、お礼の権利があるよ。

### o05  オニ  難しさ5
4枚のカードがあります。どのカードも、片面は数字、もう片面は色です。
いま見えているのは、「3」「8」「赤」「青」の4枚です。
ルールは、「数字が偶数なら、裏は赤」です。
このルールが守られているか、確かめます。めくる必要があるカードは?

- **1. 「8」と「青」 ◎**
- 2. 「8」と「赤」
- 3. 「3」と「赤」
- 4. 「3」と「青」

解説: ルールをやぶっているカードがないか、探します。
・「8」は偶数です。裏が赤でなければ、ルールにそむくので、めくります。
・「青」は赤ではありません。裏が偶数だと、ルールにそむくので、めくります。
・「3」は偶数ではないので、裏が何色でも、ルールに関係ありません。
・「赤」は、裏が何の数字でも、ルールにそむきません。
ヒント: ルールが、やぶられる可能性のあるカードは?

### q83  地理歴史（難しい）  難しさ4
日本の都道府県のうち、いちばん東にある場所を、持っているのは?

- 1. 北海道
- **2. 東京都 ◎**
- 3. 沖縄県
- 4. 青森県

解説: 日本のいちばん東の場所は、東京都の南鳥島です。東京から、約1900kmはなれた太平洋にある、小さな島です。北海道の根室などは、本土の中でいちばん東にありますが、日本全体では、南鳥島が最東端です。
ヒント: 東京から、はるか東の太平洋に、小さな島があるよ。
