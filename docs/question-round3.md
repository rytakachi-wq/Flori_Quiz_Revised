### q29  社会（ふつう）  難しさ2
道で財布を拾って、交番に届けました。持ち主が、決められた期間内に現れなかったら、財布は、どうなる?

- **1. 拾った人が、もらえることがある ◎**
- 2. 警察のものになる
- 3. 必ず、すてられる
- 4. 国のお金になる

解説: 落とし物は、交番に届けると、警察が保管します。持ち主が、3か月以内に現れないときは、拾った人が、もらえる権利を得ます。ただし、拾った人が、その権利を放棄することもできます。
ヒント: 拾って届けた人には、お礼の権利があるよ。

### o05  オニ  難しさ5
4枚のカードがあります。どのカードも、片面に数字、もう片面に色が書いてあります。いま見えている面は、「3」「8」「赤」「青」です。「数字が偶数なら、裏の色は必ず赤」というルールが、守られているか、確かめたいです。めくる必要があるカードは?

- **1. 「8」と「青」 ◎**
- 2. 「8」と「赤」
- 3. 「3」と「赤」
- 4. 「3」と「青」

解説: 「8」は偶数なので、裏が赤かどうか、確かめる必要があります。「青」は、赤ではないので、裏が偶数だと、ルールにそむきます。だから、裏が偶数でないか、確かめる必要があります。「3」は偶数ではないので、裏が何色でも、ルールに関係ありません。「赤」の裏が奇数でも偶数でも、ルールは、守られています。
ヒント: ルールが、やぶられる可能性のあるカードは?

### q87  数学（難しい）  難しさ4
ハワイは、日本より19時間おそい時刻です。日本が、1月1日の正午のとき、ハワイは、何月何日の何時?

- **1. 12月31日の午後5時 ◎**
- 2. 1月1日の午後5時
- 3. 12月31日の午前5時
- 4. 1月2日の午前5時

解説: 日本の正午から、19時間もどします。まず12時間もどして、1月1日の午前0時。さらに7時間もどすと、12月31日の午後5時(17時)です。日付も、前の日にもどります。
ヒント: 19時間もどすと、日付は、どうなるかな?

### q83  地理歴史（難しい）  難しさ4
正方形の紙を、半分に折り、もう1度半分に折って、4つ折りにします。折り目が集まった角を、はさみで、まっすぐ切り落として、広げます。まん中の穴は、どんな形?

- **1. 四角形(ひし形) ◎**
- 2. 三角形
- 3. 円
- 4. 穴は、あかない

解説: 4つ折りにした紙を、広げると、同じ形が、4つ並びます。折り目が集まる角を、まっすぐ切り落とすと、広げたとき、紙のまん中に、4つの辺をもつ、四角形の穴があきます。
ヒント: 切り落とした三角形が、広げると、いくつ並ぶかな?

### q84  言語文化（難しい）  難しさ4
歌舞伎で、客席の中を通って、舞台につながる、役者が出入りする、細長い道を、何という?

- **1. 花道 ◎**
- 2. 通り道
- 3. 橋掛かり
- 4. 舞台袖

解説: 歌舞伎の「花道」は、客席を通って、舞台につながる道です。役者が、ここを通って登場したり、見せ場を演じたりします。「橋掛かり」は、能の舞台にある、似たものです。
ヒント: 能の舞台にある「橋掛かり」と、似た役目の道だよ。
