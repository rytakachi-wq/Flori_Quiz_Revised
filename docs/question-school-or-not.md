# 学校で習う問題・習わない問題(ジャンル別)

利用者の指定で、一覧から q69・q71・q74・q101 をのぞき、q96・q97 を含む指定の問題を「習わない」、q90 を「習う」に入れかえた版です(問題データ自体は変えていません)。

習う 45問 / 習わない 51問

## 習う(ジャンル別)

### 算数（ふつう）(5問)
- q17: 10時20分の1時間50分後は何時になる? → **12時10分**
- q20: 次のうち素数(1とその数自身でしか割り切れない、2以上の整数)はどれ? → **17**
- q28: 2、3、5、8、12、□ … □に入る数は? → **17**
- q41: 三角形の3つの角の大きさを全部足すと何度? → **180度**
- q98: 1本80円のえんぴつを3本買いました。500円玉で払うとき、おつりはいくら? → **260円**

### 数学（難しい）(7問)

- q75: 2つの整数を足すと20、かけると91になります。大きい方から小さい方を引くといくつになる? → **6**
- q77: ある数を3で割ると2余り、5で割ると3余り、7で割ると2余ります。1番小さい、そのような数は? → **23**
- q87: お店が800円で買ってきた品物があります。買った値段の25%のもうけをのせて、値札をつけました。その値札の値段の10%を… → **100円**
- q88: 水槽が満杯になるまで水を入れます。大きい蛇口は20分、小さい蛇口は30分で、いっぱいになります。同時に使うと何分? → **12分**
- q90: 1から9までの数字を、1つずつ使って3×3のますに並べます。たて・よこ・ななめの、どの3つを足しても15になるように並べ… → **5**

### 理科（ふつう）(4問)

- q92: 雷が光ってから6秒後に音が聞こえました。音は1秒に約340m進みます。雷はおよそ何km先で鳴った? → **約2km**

## 習わない(ジャンル別)

### 算数（ふつう）(5問)
- q23: 1本のひもを真ん中で切ります。できたひもを全部そろえて重ね、また真ん中で切ります。このように合わせて3回、真ん中で切ると… → **8本**
- q43: 1から9までの数字カード(1枚ずつ)から、2枚を選んで足して10になる組み合わせは全部で何組? → **4組**
- q96: うるう年は4年に1度あります。うるう年の2月は何日まである? → **29日**
- q97: 3日と6時間は全部で何時間? → **78時間**
- q99: 最初に10人乗っていたバスが、停留所ごとに3人降りて、新たに2人が乗ります。3つめの停留所を出たとき、何人乗っている? → **7人**

### 理科（ふつう）(5問)
- q03: 晴れた日の正午ごろ、地面にできる影の長さは朝や夕方と比べてどうなる? → **朝や夕方より短い**
- q06: 夏に冷たい飲み物を入れたコップの外側に水滴がつきます。この水はどこから来た? → **空気中の水蒸気が冷やされた**
- q16: 磁石にくっつくものは次のうちどれ? → **鉄のクギ**
- q19: 月が光って見えるのはなぜ? → **太陽の光を、はね返しているから**
- q31: お湯がぐつぐつと沸騰しています。火を強くするとお湯の温度はどうなる? → **100度のまま**

### 科学（難しい）(4問)
- q91: カメレオンが体の色を変える主な理由と考えられているのは? → **気持ちを仲間に伝えたり、体温を調節したりするため**
- q93: 雨上がりに虹が見えるとき、太陽はどの方向にある? → **自分の背中側**
- q94: ホッキョクグマの毛が白く見える理由はどれ? → **毛が透明で光がはね返るから**
- q95: 飛行機の窓の下のほうには小さな穴があります。何のためにある? → **くもりや割れを防ぐため**

### 社会（ふつう）(1問)
