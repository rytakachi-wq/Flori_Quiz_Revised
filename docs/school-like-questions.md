# A. 今ある問題(差しかえ候補 51問)

## 理科(13問)

- **q03**(難1) 晴れた日の正午ごろ、地面にできる影の長さは朝や夕方と比べてどうなる?
  - 選択肢:★朝や夕方より短い / 朝や夕方より長い / 朝や夕方と同じ / 影はできない
  - ヒント:影は太陽が高いほど短くなります。太陽が1番高いのは何時ごろでしょう?
  - 解説:正午ごろは太陽が1番高い位置にあるので、影は1日のうちで1番短くなります。朝や夕方は太陽が低いので、影が長く伸びます。
- **q06**(難1) 夏に冷たい飲み物を入れたコップの外側に水滴がつきます。この水はどこから来た?
  - 選択肢:コップの中の飲み物がしみ出した / 氷が溶けた水が飛んできた / ★空気中の水蒸気が冷やされた / コップが水を作った
  - ヒント:空気の中には目に見えない水(水蒸気)が入っています。それが冷たいコップにふれると…?
  - 解説:空気中には目に見えない水蒸気が含まれています。冷たいコップに触れて冷やされると、水滴に変わってコップの外側につきます。
- **q15**(難1) 空全体を10として雲が9〜10をしめているときの天気はどれ?
  - 選択肢:快晴 / 晴れ / 雨 / ★くもり
  - ヒント:雲の量がほとんど、空全体に広がっています。
  - 解説:天気は空全体を10としたとき、雲の量が0〜1なら「快晴」、2〜8なら「晴れ」、9〜10なら「くもり」と決められています。雨がふっているかどうかは、雲の量とはべつに決まります。
- **q16**(難1) 磁石にくっつくものは次のうちどれ?
  - 選択肢:10円玉 / アルミ缶 / ★鉄のクギ / 純金
  - ヒント:クギは何でできているでしょう?
  - 解説:磁石にくっつくのは鉄などの金属です。10円玉は銅、アルミ缶はアルミニウム、純金は金でできていて、どれもくっつきません。
- **q19**(難1) 月が光って見えるのはなぜ?
  - 選択肢:★太陽の光を、はね返しているから / 自分で光っているから / 地球の光を、うけているから / 星の光を、集めているから
  - ヒント:夜の空で太陽のかわりをしているのは?
  - 解説:月は自分では光りません。太陽の光が当たってそれをはね返しているので光って見えます。月の形が変わって見えるのも、太陽の光が当たるところがちがうからです。
- **q31**(難2) お湯がぐつぐつと沸騰しています。火を強くするとお湯の温度はどうなる?
  - 選択肢:★100度のまま / 上がる / 下がる / 分からない
  - ヒント:沸騰している間は水の温度は変わりません。火の力は何に使われているのでしょう?
  - 解説:水は100度で沸騰して水蒸気に変わります。沸騰している間は火を強くしてもお湯の温度は100度のままです。火の力は水を水蒸気に変えるために使われ、水の量が早く減るだけです。
- **q39**(難2) 植物が光合成で空気中から取り入れる気体はどれ?
  - 選択肢:★二酸化炭素 / 酸素 / 窒素 / 水素
  - ヒント:人が息をはくときに出る気体です。
  - 解説:植物は光を受けて二酸化炭素と水から、養分と酸素をつくります。これを光合成といいます。人間が息をはいたときに出る二酸化炭素を、取り入れています。
- **q40**(難2) ふりこが1往復する時間は何によって決まる?
  - 選択肢:★ふりこの長さ / おもりの重さ / ふれはばの大きさ / ふり始めの力の強さ
  - ヒント:糸を長くするとゆれ方がゆっくりになります。
  - 解説:ふりこの1往復の時間は、ふりこの長さだけで決まります。おもりの重さや、ふれはばを変えてもほとんど変わりません。長いほど、ゆっくり動きます。
- **q62**(難3) かん電池2こを使って、豆電球をいちばん明るくつけるつなぎ方はどれ?
  - 選択肢:並列(縦に2列で並べる) / ★直列(横に1列で並べる) / 1こだけにする / つながない
  - ヒント:かん電池を1列にならべます。
  - 解説:かん電池を横に1列にならべてつなぐ(直列つなぎ)と、電気を流す力が2倍になって、豆電球が明るくつきます。縦に2列にならべてつなぐ(並列つなぎ)では、1このときとほぼ同じ明るさです。
- **q63**(難3) 食塩を水にとかしたとき、とけた食塩はどうなっている?
  - 選択肢:★目には見えないが、重さは残っている / 目にも見えないし、重さもなくなってしまう / 水より軽くなって、水面にうかんでくる / 水の外に、少しずつ出ていってしまう
  - ヒント:とけても食塩そのものはなくなりません。
  - 解説:食塩は水にとけると目に見えなくなりますが、なくなったわけではありません。とかす前と後で全体の重さは変わりません。
- **q86**(難4) 夏の夜、南の空に見える、さそり座の赤い1等星はどれ?
  - 選択肢:シリウス / ベテルギウス / ★アンタレス / ベガ
  - ヒント:さそり座の心臓の位置にある星です。
  - 解説:さそり座の赤い1等星はアンタレスです。「火星に対抗するもの」という意味で赤く光ります。シリウスはおおいぬ座、ベテルギウスはオリオン座、ベガはこと座の星です。
- **q27**(難2) コップの縁まで水を入れて、氷を浮かべました。氷が全部溶けると水面はどうなる?
  - 選択肢:あふれる / 水面が下がる / 水面が少し上がる / ★水面は変わらない
  - ヒント:浮かんでいる氷は水面の下にもその分だけ沈んでいます。その分はどうなるでしょう?
  - 解説:浮かんでいる氷は自分と同じ重さの水の分だけ水面の下に沈んでいます。溶けるとちょうどその分の水になるので、水の高さは変わりません。
- **q52**(難3) はかりの上に水の入ったコップを載せています。コップに触らずに指を1本、水の中に入れました。はかりの数字はどうなる?
  - 選択肢:★増える / 減る / 変わらない / 0になる
  - ヒント:指が水を押すと水は指をどうするかな? 押す力と押し返す力を考えよう。
  - 解説:指を水に入れると水は指を上に押し上げます。その反対に指は水を下に押し返すので、はかりにはその押し返す力の分が加わって数字が増えます。

## 国語(15問)

- **q14**(難1) 「うろうろ」「ニコニコ」「ツルツル」のように、物事の様子を表す言葉を何という?
  - 選択肢:反対語 / 敬語 / ★擬態語 / 擬音語
  - ヒント:音をまねた言葉ではなく、ようすを表す言葉です。
  - 解説:「うろうろ」「ニコニコ」「ツルツル」のように、音ではなく、ようすや気持ち・手ざわりなどを表す言葉を擬態語といいます。「ワンワン」「ガチャン」のように、鳴き声や音をまねた言葉は擬音語です。
- **q24**(難2) 「食べる」ことを尊敬語にするとどれになる?
  - 選択肢:いただく / 参る / 申し上げる / ★召し上がる
  - ヒント:尊敬語とは先生など目上(年上や、立場が上の人)をうやまう(大切にする)言いかたです。
  - 解説:相手(先生など)の動作を敬う言いかたを、尊敬語と言います。「食べる」の尊敬語は「召し上がる」です。「いただく」は自分が食べるときに使う、へりくだった言いかたです。
- **q33**(難2) 慣用句「ねこの手も借りたい」は、どんなときに言う?
  - 選択肢:ひまでたいくつなとき / ねこが好きなとき / 手をけがしたとき / ★とてもいそがしいとき
  - ヒント:ねこの手はあまり役に立ちません。それでも借りたいのは、どんなときでしょう?
  - 解説:「ねこの手も借りたい」は、とてもいそがしくてだれでもいいから、手伝ってほしいときに言います。ねこの手でも借りたいほど、という意味です。
- **q35**(難2) ことわざ「雨降って地固まる」の意味は?
  - 選択肢:★ケンカのあとは、前より仲よくなる / 雨がふると、道がぬかるんで歩きにくくなる / 雨の日は、外で遊ばないほうがよい / 悪いことは、いつまでも続いてしまう
  - ヒント:雨がふったあとの地面はどうなるかな?
  - 解説:「雨降って地固まる」は、もめごとや困ったことのあとかえって前よりしっかりして、よい状態になるという意味です。雨のあとに地面がかたまることから言います。
- **q36**(難2) ことわざ「枯れ木も山の□わい」の□に入る言葉は?
  - 選択肢:わざ / ふる / あじ / ★にぎ
  - ヒント:枯れ木があると山が少しどうなるかな?
  - 解説:「枯れ木も山のにぎわい」はつまらないものでもないよりはましだ、という意味です。枯れた木でも山にあれば、山を少しにぎやかに見せることから言います。
- **q38**(難2) 「顔が広い」とはどんな意味?
  - 選択肢:顔がふつうより大きい / ★知り合いがたくさんいる / 化粧がとても上手だ / 目立つのが大好きだ
  - ヒント:「広い」のは顔の大きさではなく、何でしょう?
  - 解説:「顔が広い」は知り合いや友だちが多く、いろいろな人に知られている、という意味です。顔の大きさとは関係ありません。
- **q47**(難3) 「話し合いが煮詰まってきた」の「煮詰まる」の本来の意味は?
  - 選択肢:★十分に話し合って、結論に近づく / 考えがまとまらず、行きづまってしまう / 話が長くなって、みんなが疲れてしまう / 話し合いの中身が、うすくなってしまう
  - ヒント:料理の「煮詰める」を思い出してみましょう。汁気がなくなるとどうなるでしょう?
  - 解説:「煮詰まる」は本来、十分に話し合って結論が出る段階に近づくという意味です。料理で汁気がなくなってできあがりに近づくことから来ています。「行きづまる」という意味で使う人も多いですが、本来の意味ではありません。
- **q55**(難3) 「雨が降らないとは限らない」はどういう意味?
  - 選択肢:★雨が降るかもしれない / 雨が降らないかもしれない / 必ず雨が降る / 必ず雨は降らない
  - ヒント:「ない」が2回出てきます。打ち消し合うのでしょうか?
  - 解説:「降らないとは限らない」は、「降らないとは言いきれない」という意味です。つまり、「降るかもしれない」ということです。「ない」が2回出ると、打ち消しが打ち消されます。
- **q60**(難3) 四字熟語「温故知新」の意味はどれ?
  - 選択肢:新しいことを学んで、古い考えを捨てること / 古い友だちと、新しい友だちを、比べること / 昔の話を、何度もくり返すこと / ★古いことを学んで、新しい考えを得ること
  - ヒント:「故」は「ふるい」、「新」は「あたらしい」という意味です。
  - 解説:「温故知新」は古いことをよく学び、そこから、新しい考えや知識を得る、という意味です。「故きを温ねて新しきを知る」と読みます。
- **q61**(難3) 先生など、自分より目上(年上や、立場が上)の人が何かを「見る」ことを、尊敬語で言うとどれ?
  - 選択肢:拝見する / ★ご覧になる / 見ています / ご覧になられる
  - ヒント:目上の人の動作を高めて言う言い方です。
  - 解説:「見る」の尊敬語は「ご覧になる」です。「拝見する」は自分が見るときに使う、けんじょう語です。「ご覧になられる」は、尊敬の言い方をかさねすぎた言い方(二重敬語)なので、ふつうは使いません。「見ています」はふつうの言い方です。
- **q79**(難4) 故事成語(むかしの話から生まれた言葉)である、「杞憂」の意味はどれ?
  - 選択肢:心配していたことが、起こらずに終わる / 心配していたことが、本当に起こってしまう / 心配しないといけないことを、軽く考えてしまうこと / ★心配しなくてよいことを、心配しすぎること
