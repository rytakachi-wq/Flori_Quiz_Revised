## 難しさ1 / 生活(5問)

### q01

> 水1滴と水1滴をくっつけると水は何滴になる?

- 1. 0滴
- **2. 1滴**
- 3. 2滴
- 4. 3滴

**答え: 2. 1滴**  
ヒント: 「1+1がいつも2になる」とは限りません。水の粒がくっつくところを思い浮かべてみましょう。  
解説: 水滴はくっつくと1つの大きな水滴になります。1+1がいつも2になるとは限らない、というひらめきの問題です。


### q04

> ろうそくが5本、火がついています。風が吹いて2本の火が消えてしまいました。ろうそくは全部で何本残っている?

- 1. 3本
- **2. 5本**
- 3. 2本
- 4. 0本

**答え: 2. 5本**  
ヒント: 問題文をよく読もう。消えたのは何かな?  
解説: 消えたのは「火」だけでろうそく自体はなくなっていません。火がついているのは3本ですが、ろうそくは5本残っています。


### q05

> かけっこの最中にあなたは2番目を走っていた人を抜きました。あなたは今、何番目?

- 1. 1番目
- **2. 2番目**
- 3. 3番目
- 4. 4番目

**答え: 2. 2番目**  
ヒント: 「抜く」と抜いた相手と場所が入れ替わります。1番目の人は抜いたでしょうか?  
解説: 2番目の人を抜くとその人の場所に入れ替わります。だからあなたが2番目で抜かれた人は3番目になります。1番目の人は抜いていないので、1番にはなれません。


### q07

> 1年のうち30日までしかない月は、2月を除くと4月・6月・9月と、あと1つあります。それは何月?

- 1. 7月
- 2. 8月
- **3. 11月**
- 4. 12月

**答え: 3. 11月**  
ヒント: 31日まである月を1月から順に数えてみましょう。7月と8月は続けて31日です。2月は28日(うるう年は29日)までなので、30日までの月には入りません。  
解説: 30日までの月は2月を除くと、4月・6月・9月・11月の4つです。他の月は31日まであります。


### q21

> うるう年は4年に1度あります。うるう年の2月は何日まである?

- 1. 27日
- 2. 28日
- **3. 29日**
- 4. 30日

**答え: 3. 29日**  
ヒント: 1年は365日より少しだけ長いので、ずれを直す日が必要です。  
解説: うるう年の2月は29日までです。地球が太陽の周りを1周する日数がちょうど365日ではないので4年に1度1日増やしてずれを直しています。

### q28

> ろうそくは燃やすと、燃えかすが1つ残ります。燃えかす4つで新しいろうそくを1本作れます。最初にろうそくが16本あるとき、全部で何本燃やせる?

- 1. 20本
- **2. 21本**
- 3. 22本
- 4. 24本

**答え: 2. 21本**  
ヒント: 燃えかすで作ったろうそくも燃やすと、燃えかすが出るよ。  
解説: まず16本を燃やして、燃えかすが16個。それで4本作って燃やすと、燃えかすが4個。それでまた1本作って燃やします。16+4+1=21本です。


### q41

> ある月の3日は月曜日です。では30日は何曜日?

- **3. 日曜日**
- 4. 火曜日

**答え: 3. 日曜日**  
ヒント: 7日たつと、同じ曜日に戻るよ。  
解説: 3日と30日は、27日離れています。27÷7=3余り6なので月曜日から6日進みます。月曜日の6日あとは日曜日です。


### q43

- 4. 9切れ

解説: 3本ともピザの真ん中を通るように切ると、6切れです。でも、切り口が互いに、真ん中以外の場所で交わるように切ると、7切れになります。1回目で2切れ、2回目で4切れ、3回目は前の2本と交わるので、さらに3切れ増えて、7切れです。

> 6本のマッチ棒を全部使って、同じ大きさの正三角形を4つ作ります。マッチ棒は折ったり、切ったりしません。どうすればいい?

- **1. 三角すい(立体)の形に組む**
- 2. 星の形に重ねて置く
- 3. 同じ平面に、4つ並べる
- 4. 作れない

**答え: 1. 三角すい(立体)の形に組む**  
ヒント: 平面だけで考えないで立体にしてみよう。  
解説: 平面では、6本で正三角形は最大でも2つしか作れません。でも立体にして、三角すいの形に組むと、4つの面がすべて同じ大きさの正三角形になります。底に3本、そこから頂点へ3本を立てます。


### o10

> 3人が1人10円ずつ、合計30円を出して、ホテルに泊まりました。宿代は25円だったのでボーイが5円を返しに行き、2円を自分の物にして、3人に1円ずつ返しました。3人が出したお金は、1人9円で合計27円。これにボーイの2円を足すと、29円です。あと1円はどこへ消えた?

- 1. ホテルの人が1円を盗んだ
- **2. 1円は消えていない。足し方が間違っている**
- 3. ボーイがまだ1円持っている
- 4. 3人のうちの1人が、1円を盗んだ

**答え: 2. 1円は消えていない。足し方が間違っている**  
ヒント: 27円の中身は何と何かな?  
解説: 3人が出した27円は宿代の25円と、ボーイの2円を合わせたものです。ボーイの2円はすでに27円の中に入っているので、足してはいけません。正しくは、27円+返したお金3円=30円、または、25円+2円+3円=30円でぴったり合います。
