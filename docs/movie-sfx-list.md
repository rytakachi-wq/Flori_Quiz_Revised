# ものがたりの効果音リスト(希望・案)

**2026-11-16 に、このリストの音を、入れた**(`src/live2d/story-sfx.js`。ゲームの音のファイルが使えるものは それを、ほかは ブラウザの中で作る[WebAudio]。耳での確認は まだ。気に入らない音は、名前を言ってください)。

(以下は、入れる前に作った リストです。)
「いまある音」=ゲームに すでに入っている音(`assets/audio/`、`audio.js` の SE)で、使いまわせるもの。
「新しく」=作る(または 効果音ラボなどで 探す)もの。✔ をつけたものから、入れていきます。

## 共通(どの お話にも)
| 音 | いつ | いまある音 / 新しく |
|---|---|---|
| 次へ・閉じる・飛ばす ボタン | ボタンを押したとき | いまある音(`button`) |
| ふきだし・文字が出る | 新しいセリフが出るとき | 新しく(ぽん。小さく やわらかい音) |
| 場面が かわる | 次のコマへ行くとき | 新しく(さらっ。すこしだけ) |
| 札(第○話)が出る | 話数の札が出る・消える | 新しく(しゃらん。巻物が ひらく音) |
| フロリが 歩く | 歩く場面(足音) | 新しく(ぽてぽて。やわらかい足音) |
| フロリが ぴょんと はねる | `hops` の場面 | いまある音(`floriHop`) |
| びっくり(!マーク) | `fx_exclaim` が出るとき | 新しく(ピコン!) |
| ひらめき(電球) | 電球が ひかるとき | いまある音(`correct` のチャイム)か 新しく(ピカーン) |
| ハート・きらきら | ハートが のぼる場面 | 新しく(きらきら) |
| ぷんぷん(おこりのマーク) | `fx_anger` | 新しく(ぷんぷん) |

## 入れるときの方針(案)
- まず「共通」と、いまある音で足りるもの(ボタン・ぴょん・ひらめき)から入れる。
- 音量は、設定の「効果音」のつまみに合わせる(`se`)。BGM より 小さめ。
- 新しく 作る音は、効果音ラボ などの 利用できる素材を探すか、ブラウザの中で作る(WebAudio)。素材を使うときは、スタッフクレジットに 書く。
